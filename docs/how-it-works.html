🏗️ ARCHITECTURE

全体アーキテクチャ

Claude.ai → Cloudflare Tunnel → LXC上のMCPサーバー → 任意のSSHホスト。

# リクエストの流れ Claude.ai (ブラウザ / モバイル) │ │ POST /mcp?key=uk_xxx │ HTTPS (Anthropic Cloud → Cloudflare Tunnel) ▼ ┌──────────────────────────────────────┐ │ LXC: ssh-mcp-server (port 3000) │ │ │ │ Express + Streamable HTTP MCP │ │ ?key= → KeyStore → CallerContext │ │ │ │ SSH Session Manager (in-memory) │ │ session_token = SHA-256 capability │ └──────────────────┬───────────────────┘ │ SSH (port 22) ▼ Proxmox / LXC / VM / NAS
🔑 AUTHENTICATION

3層認証モデル

門番（API Key） → 接続権（User Key） → 操作権（Session Token）

LAYER 1

Admin Key

環境変数で設定。サーバー管理専用。User Keyの発行/一覧/削除、全セッションの閲覧と操作が可能。SSHの新規接続は不可（権限分離）。

?key=ak_a8f3b2c1...
LAYER 2

User Key

Admin KeyでMCP経由発行。Claude.aiのカスタムコネクターURLに入れて使う。SSH接続の作成権を持つ。自分のセッションのみ一覧可能。

?key=uk_84e17ac6...
LAYER 3

Session Token

ssh_connectの戻り値。SHA-256ハッシュで、持っていれば誰でも操作可能（ケイパビリティトークン）。会話履歴に自然に残るので次のメッセージで継続利用。

sess_e7b2a4f1c3d8...
⏱️ SESSION LIFECYCLE

セッションのライフサイクル

$ ssh_connect(host, user, pass) → session_token: sess_a3f8b2c1e7d4... → state: CREATED (TTL: 1日) $ ssh_execute(sess_..., "uptime") → state: USED (TTL: 3ヶ月 from last use) # 3ヶ月後... → state: EXPIRED (auto-disconnected) # または明示的に: $ ssh_disconnect(sess_...) → state: DISCONNECTED

🆕 未使用セッション

ssh_connect後、ssh_execute/upload/downloadを一度も実行していない状態。最終使用から1日で自動切断。放置防止。

✅ 使用済セッション

ssh_execute/upload/downloadを1回以上実行した状態。最終使用から3ヶ月で自動切断。長期利用を想定。

🔒 SECURITY

セキュリティ設計

🔐 通信の暗号化

Cloudflare Tunnel経由のHTTPS。Claude.ai → Anthropic Cloud → Cloudflare → LXC 全経路がTLS暗号化。直接ポート公開なし。

🗑️ SSH認証情報の非保存

パスワード/秘密鍵はMCPリクエスト内でのみ使用。サーバーに保存もログ出力もしない。再起動で全セッション消去。

🔗 ケイパビリティトークン

session_tokenはSHA-256ハッシュ。SSH接続情報を逆算不可能。256bitでブルートフォース不可能。

📂 ソースコード公開

全コードがGitHubで公開。認証・セッション管理の実装を誰でも監査可能。

セットアップは4ステップ

LXCデプロイ → Cloudflare Tunnel → コネクター登録 → 完了。
